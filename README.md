# java-lotto-precourse

## 목표
- TDD(Test-Driven Development) 를 통해 기능 단위로 테스트 작성 및 검증
- 클래스의 단위 세분화 와 명확한 책임 분리(SRP) 를 실천
- TDD, SRP 실천에 익숙해지기

## 기능
- [x] 로또 발행 기능
  - 금액 입력
  - 입력한 금액에 따라 로또 티켓 자동 발행 (1,000원 단위)
  - 발행한 로또 오름차순 출력
- [x] 당첨 번호 입력
  - 당첨 번호 6자리 수동 입력
  - 보너스 번호(당첨 번호 6자리와 중복 불가)
- [ ] 로또 등수 계산 기능 
  - 구입한 로또 번호와 당첨 번호를 비교하여 등수 산출
- [ ] 수익률 계산 기능
  - 로또 구입 금액 대비 당첨 금액을 활용해 수익률 산출
- [ ] 등수 및 수익률 출력 기능
  - 사용자에게 각 로또의 당첨 등수와 전체 수익률 출력


## 테스트 사항
- 금액 확인
  - 1000원 단위의 금액이 입력 되었는가
- 당첨 번호 입력
  - 중복되지 않은 6개의 숫자가 입력 되었는가
  - 보너스 번호가 앞선 6개의 숫자와 중복되지 않았는가
- 로또 등수 검증
  - 등수 계산 로직의 정확성
- 로또 수익률 검증
  - 총 당첨 금액 대비 구입 금액 비율이 올바르게 산출되는지 테스트
